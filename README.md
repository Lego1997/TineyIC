Enter a stock ticker. Watch Warren Buffett, Charlie Munger, Benjamin Graham, Peter Lynch, Howard Marks, and Li Lu argue over whether to buy, hold, or sell. Get a scorecard, investment memo, and disagreement analysis -- all generated by multi-agent AI debate.

---

## How It Works

TineyIC creates AI personas of 6 legendary value investors, each distilled from decades of their public writings and investment philosophy. These personas analyze real financial data about any public company, then engage in a structured 4-phase debate:

1. **Opening Statements** -- Each investor presents their initial thesis
2. **Cross-Examination** -- Investors challenge each other (with a rotating devil's advocate)
3. **Rebuttal** -- Each investor responds to criticisms and refines their position
4. **Final Verdict** -- Buy / Hold / Sell vote with confidence level and reasoning

The debate uses anti-convergence controls to prevent groupthink -- investors maintain their distinct philosophies even under pressure.

## Features

- **6 Philosophy-Driven Personas** -- Not shallow role-plays. Each persona is grounded in 20-30 years of real writings (annual letters, books, speeches)
- **Real Financial Data** -- Auto-fetches from yfinance (price, fundamentals, ratios), SEC EDGAR (10-K, 10-Q filings), and news sources
- **Deep Research Pipeline** -- Optional web search + LLM synthesis covering business model, competition, management, catalysts, and analyst views
- **Structured Debate** -- 4-phase format with anti-convergence controls and rotating devil's advocate
- **Investment Memo** -- Full narrative with executive summary, thesis, risks, valuation analysis, and verdict
- **Disagreement Analysis** -- Identifies key points of contention between investors with evidence quotes
- **Scorecard** -- Buy/Hold/Sell votes from each investor with confidence scores
- **Export** -- Download results as Markdown or DOCX
- **Cost Tracking** -- Per-debate token usage and estimated cost
- **Model Selection** -- Choose between GPT-5.2 (deep reasoning) or Codex-5.3 (faster) per debate

## Quick Start

### Prerequisites

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) (Python package manager)
- An [OpenAI API key](https://platform.openai.com/api-keys) with access to GPT-5.2

### Installation

```bash
git clone https://github.com/Lego1997/TineyIC.git
cd TineyIC

# Install dependencies
uv sync

# Set your API key
echo "OPENAI_API_KEY=sk-your-key-here" > .env
```

### Run

```bash
uv run streamlit run src/tinyic/ui/app.py
```

Open the URL shown in your terminal (typically `http://localhost:8501`), enter a ticker (e.g., `AAPL`), and start the debate.

## Architecture

```
TineyIC
├── src/
│   ├── tinyic/                  # Application code
│   │   ├── personas/            # 6 investor persona definitions
│   │   │   └── configs/         # Philosophy-rich JSON configs
│   │   ├── data/                # Financial data pipeline
│   │   │   ├── pipeline.py      # Orchestrates all data fetching
│   │   │   ├── financials.py    # yfinance integration
│   │   │   ├── filings.py       # SEC EDGAR integration
│   │   │   ├── news.py          # News aggregation
│   │   │   └── research.py      # Web search + LLM synthesis
│   │   ├── debate/              # Debate engine
│   │   │   ├── orchestrator.py  # TinyWorld subclass, 4-phase debate
│   │   │   ├── extraction.py    # Vote extraction from agent memory
│   │   │   └── memo.py          # Investment memo generation
│   │   ├── export.py            # Markdown/DOCX export
│   │   └── ui/
│   │       └── app.py           # Streamlit web interface
│   └── tinytroupe/              # Forked TinyTroupe framework
└── tests/                       # Test suite (261 tests)
```

**Key design decisions:**
- Built on [Microsoft TinyTroupe](https://github.com/microsoft/TinyTroupe) (v0.6.0 fork) for multi-agent persona simulation
- Anti-convergence: persona-specific reinforcement prompts injected every turn + rotating devil's advocate
- Graceful degradation: each data source fails independently without breaking the pipeline
- Pydantic models throughout for type safety and structured extraction

## Configuration

| Variable | Description | Default |
|----------|-------------|---------|
| `OPENAI_API_KEY` | OpenAI API key (required) | -- |
| Model selection | Choose in the UI sidebar | GPT-5.2 |
| Deep Research | Toggle in the UI sidebar | Off |

Additional configuration lives in `src/tinytroupe/config.ini` for model parameters and reasoning effort.
