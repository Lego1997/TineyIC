   - Takes dict mapping persona name -> reasoning text
   - Creates TfidfVectorizer(stop_words='english', min_df=1)
   - Fits and transforms the texts
   - Computes pairwise cosine_similarity matrix
   - Returns {"pairs": [(name_a, name_b, float_similarity), ...], "max_similarity": float}
   - Pairs are upper-triangle only (no self-comparisons, no duplicates)

5. Test class TestMeasureDifferentiation:
   - test_measure_differentiation_structure: Call with 2 simple texts, assert result has "pairs" key (list) and "max_similarity" key (float), assert len(pairs) == 1 for 2 inputs

   - test_fixture_has_minimum_personas: Load fixture, assert len(personas) >= 3
   - test_persona_differentiation_on_fixture: Load fixture, extract name->reasoning_text dict, call measure_differentiation(), assert every pair's similarity < SIMILARITY_THRESHOLD (0.70). On failure, the assertion message must include which persona pair exceeded the threshold and by how much.
