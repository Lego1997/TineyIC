# Plan 11-01: Model Selection Dropdown with Runtime Override

## Goal
Users can choose which LLM model powers the debate via a sidebar dropdown, with the selection applied at runtime without editing config files.

## Requirements Covered
CONFIG-01, CONFIG-02, CONFIG-03

## Architecture

### Model Registry
Define `MODEL_OPTIONS` in `src/tinyic/constants.py` — a list of dicts with `id`, `display_name`, and `description`. This is the single source of truth for available models. The default model is read from `config_manager.get("model")` at UI init time.

### Sidebar Dropdown
Add a `st.selectbox` to `render_sidebar()` between the persona section and "Start Debate" button. Format: `"GPT-5.2 — Deep reasoning, highest quality"`. Disabled during active debate (uses existing `disabled` flag).

### Runtime Override in Worker
Pass `selected_model` from session state → `_start_debate()` → `_debate_worker()` args. In worker, call `config_manager.update("model", selected_model)` before any LLM calls. Restore original model in `finally` block.

The model override covers **all LLM calls in the worker**: debate rounds, vote extraction, memo generation, and disagreement extraction. This is intentional — the user selects a model for the entire session, not just the debate portion.

### Thread Safety
ConfigManager is a global singleton. Since Streamlit is single-user and debates are sequential (one at a time), the global update is safe. The `finally`-block restore prevents model leakage between sessions.

**Action (app.py — render_sidebar):** After the persona section divider (line ~173), add a model selectbox before "Start Debate":

```python
st.subheader("Model")
from tinyic.constants import MODEL_OPTIONS
from tinytroupe import config_manager

model_labels = [f"{m['display_name']} — {m['description']}" for m in MODEL_OPTIONS]
model_ids = [m["id"] for m in MODEL_OPTIONS]

current_model = config_manager.get("model")
default_idx = model_ids.index(current_model) if current_model in model_ids else 0

selected_idx = st.selectbox(
    "LLM Model",
    range(len(model_labels)),
    format_func=lambda i: model_labels[i],
    index=default_idx,
    disabled=disabled,
    key="model_select",
)
st.session_state.selected_model = model_ids[selected_idx]

st.divider()
```

### Task 2: Pass model to debate worker and apply override
**File:** `src/tinyic/ui/app.py`

**Action (_start_debate):**
- Read `selected_model = st.session_state.get("selected_model", "")`
- Pass as additional arg to `_debate_worker()` Thread target

**Action (_debate_worker):**
- Accept `selected_model=None` parameter
- At the top, before any LLM calls, override and wrap entire body in try/finally:

```python
from tinytroupe import config_manager
original_model = config_manager.get("model")
if selected_model:
    config_manager.update("model", selected_model)
try:
    # ... entire existing worker body ...
finally:
    config_manager.update("model", original_model)
```

The `finally` block ensures the original model is restored even if the worker crashes, preventing model leakage to subsequent sessions.
