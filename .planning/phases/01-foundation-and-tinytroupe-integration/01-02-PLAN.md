    **Step 1: Audit `_raw_model_call()` in `src/tinytroupe/clients/openai_client.py`**

    Read the method and check these specific things:

    A) **Model detection for GPT-5.2**: Look for conditionals that detect reasoning models. There should be checks for models like `"o1"`, `"o3"`, `"gpt-5"`. Verify that `"gpt-5.2"` matches the detection pattern. The check is likely one of:
      - `model.startswith("gpt-5")` -- would match "gpt-5.2" (no patch needed)
      - `model in ["gpt-5", "gpt-5-mini"]` -- would NOT match "gpt-5.2" (patch needed: add "gpt-5.2")
      - `"gpt-5" in model` -- would match "gpt-5.2" (no patch needed)

    B) **Temperature removal**: For reasoning models, GPT-5.2 enforces temperature=1.0 when reasoning is active. TinyTroupe should remove the `temperature` parameter for these models. Verify this logic exists and covers GPT-5.2.

    C) **reasoning_effort passing**: Verify that `reasoning_effort` is read from config (ConfigManager) and passed as a top-level parameter to `client.chat.completions.create()`. It should NOT use the Responses API nested format `reasoning={"effort": "xhigh"}`.

    D) **max_completion_tokens vs max_tokens**: Reasoning models use `max_completion_tokens` instead of `max_tokens`. Verify TinyTroupe handles this correctly for GPT-5.2.
