2. Modify `_step()` to invoke callbacks at the right moments. The modified agent loop should be:
```python
def _step(self, timedelta_per_step=None, **kwargs):
    """Execute one debate phase: broadcast goal, then each agent acts in order."""
    if self._phase_index >= len(self.PHASE_ORDER):
        self.current_phase = DebatePhase.COMPLETE
        return {}

    phase = self.PHASE_ORDER[self._phase_index]
    self.current_phase = phase

    # Notify: phase starting
    if self.on_phase_start:
        self.on_phase_start(phase.value)

    # Broadcast the phase prompt as an internal goal
    prompt = PHASE_PROMPTS[phase].format(company=self.data_package.company_name)
    self.broadcast_internal_goal(prompt)

    # Agents act sequentially in stable order
    agents_actions: dict = {}
    for agent in self.agents:
        # Notify: agent about to act
        if self.on_agent_start:
            self.on_agent_start(agent.name, phase.value)

        actions = agent.act(return_actions=True)
        latest = agent.pop_latest_actions()
        agents_actions[agent.name] = latest
        self._handle_actions(agent, latest)

        # Notify: agent finished
        if self.on_agent_done:
            self.on_agent_done(agent.name, phase.value, latest)

    self._phase_history.append(phase.value)
    self._phase_index += 1

    if self._phase_index >= len(self.PHASE_ORDER):
        self.current_phase = DebatePhase.COMPLETE

    return agents_actions
```

IMPORTANT: The change to `agents_actions[agent.name] = latest` (using `pop_latest_actions()` instead of `act()` return value) makes the return value consistent with the reliable action source, per the established project decision that `pop_latest_actions()` is the reliable method. This is a minor improvement, NOT a behavior change -- `_handle_actions` already used `pop_latest_actions()`.

IMPORTANT: When callbacks are None, behavior is identical to the pre-modification code. All existing tests must continue to pass.

def extract_talk_content(actions):
    """Extract TALK content from a list of agent actions.

    Args:
        actions: List of action dicts from pop_latest_actions(), or None.

    Returns:
        Concatenated TALK content, or "(No response)" if no TALK actions found.
    """
    if not actions:
        return "(No response)"
    parts = []
    for action in actions:
        if isinstance(action, dict) and action.get("type") == "TALK":
            content = action.get("content", "")
            if content:
                parts.append(content)
    return "\n\n".join(parts) if parts else "(No response)"
```

**6. Debate thread management:**

CRITICAL THREADING PATTERN (from 05-RESEARCH.md): The background thread must NEVER write directly to `st.session_state`. Instead, it writes event dicts to a `queue.Queue`. The main thread (via `st.fragment`) drains the queue into `st.session_state.debate_log`. This is the only thread-safe approach for Streamlit.

```python
def _start_debate():
    """Launch the debate in a background thread."""
    st.session_state.status = "fetching"
    st.session_state.debate_log = []
    st.session_state.debate_result = None
    st.session_state.error_message = ""
    st.session_state.current_phase = ""
    st.session_state.current_agent = ""

    # Create thread-safe communication channels
    st.session_state.ui_queue = queue.Queue()
    st.session_state.stop_event = threading.Event()

    # Capture values for the thread (don't access session_state from thread)
    ticker = st.session_state.ticker
    persona_names = list(st.session_state.selected_personas)
    ui_queue = st.session_state.ui_queue
    stop_event = st.session_state.stop_event

    thread = threading.Thread(
        target=_debate_worker,
        args=(ticker, persona_names, ui_queue, stop_event),
        daemon=True,
    )
    thread.start()


def _debate_worker(ticker, persona_names, ui_queue, stop_event):
    """Background thread: fetch data -> run debate -> extract votes -> scorecard.

    IMPORTANT: This function NEVER reads or writes st.session_state.
    All communication with the UI thread is via ui_queue.put().
    """
    try:
        from tinyic.data.pipeline import build_data_package
        from tinyic.personas.registry import load_persona
        from tinyic.debate.orchestrator import DebateOrchestrator
        from tinyic.debate.extraction import extract_votes, build_scorecard
        from tinyic.debate.models import DebateResult

        # Step 1: Fetch data
        data_package = build_data_package(ticker)

        # Step 2: Load personas
        personas = [load_persona(name) for name in persona_names]

        # Step 3: Create orchestrator with streaming callbacks
        orchestrator = DebateOrchestrator(
            name=f"IC-{ticker}",
            personas=personas,
            data_package=data_package,
        )

        def on_phase_start(phase_value):
            ui_queue.put({
                "type": "phase",
                "phase": phase_value,
                "timestamp": datetime.now().isoformat(),
            })

        def on_agent_start(agent_name, phase_value):
            ui_queue.put({
                "type": "agent_start",
                "agent": agent_name,
                "phase": phase_value,
            })

        def on_agent_done(agent_name, phase_value, actions):
            content = extract_talk_content(actions)
            ui_queue.put({
                "type": "message",
                "agent": agent_name,
                "phase": phase_value,
                "content": content,
                "timestamp": datetime.now().isoformat(),
            })

        orchestrator.on_phase_start = on_phase_start
        orchestrator.on_agent_start = on_agent_start
        orchestrator.on_agent_done = on_agent_done

        # Step 4: Run debate
        ui_queue.put({"type": "status", "status": "debating"})
        orchestrator.run_debate()

        # Check for cancellation
        if stop_event.is_set():
            ui_queue.put({"type": "status", "status": "error"})
            ui_queue.put({"type": "error", "message": "Debate cancelled"})
            return

        # Step 5: Extract votes and build scorecard
        ui_queue.put({"type": "status", "status": "extracting"})
        votes = extract_votes(orchestrator)
        scorecard = build_scorecard(votes, ticker, data_package.company_name)
        transcript = orchestrator.pretty_current_interactions()

        result = DebateResult(
            ticker=ticker,
            company_name=data_package.company_name,
            scorecard=scorecard,
            phases_completed=orchestrator._phase_history,
            transcript=transcript,
        )

        ui_queue.put({
            "type": "complete",
            "result": result,
            "data_package_text": data_package.to_context_string(),
        })

    except Exception as e:
        ui_queue.put({"type": "error", "message": str(e)})


def _drain_queue():
    """Drain the ui_queue into session_state. Called from the main thread only."""
    ui_queue = st.session_state.get("ui_queue")
    if ui_queue is None:
        return

    while True:
        try:
            msg = ui_queue.get_nowait()
        except queue.Empty:
            break

        msg_type = msg["type"]
        if msg_type == "status":
            st.session_state.status = msg["status"]
        elif msg_type == "phase":
            st.session_state.current_phase = msg["phase"]
            st.session_state.current_agent = ""
            st.session_state.debate_log.append(msg)
        elif msg_type == "agent_start":
            st.session_state.current_agent = msg["agent"]
        elif msg_type == "message":
            st.session_state.current_agent = ""
            st.session_state.debate_log.append(msg)
        elif msg_type == "complete":
            st.session_state.debate_result = msg["result"]
            st.session_state.data_package_text = msg.get("data_package_text", "")
            st.session_state.status = "complete"
        elif msg_type == "error":
            st.session_state.error_message = msg["message"]
            st.session_state.status = "error"
```

**7. Debate display (st.fragment-based polling):**

Use `st.fragment(run_every=...)` for the debate display. The fragment reruns independently every 2 seconds during the debate, draining the queue and re-rendering the log. When the debate is not active, `run_every=None` stops polling.

```python
def render_debate_section():
    """Render the debate section. Uses st.fragment for auto-polling during debate."""
    # Determine polling interval: 2s during active debate, None otherwise
    is_active = st.session_state.status in ("fetching", "debating", "extracting")
    run_every = 2 if is_active else None

    @st.fragment(run_every=run_every)
    def debate_fragment():
        """Fragment that polls queue and renders debate log. Reruns independently."""
        # Drain queue into session_state (main thread only)
        _drain_queue()

        # Render all debate log entries
        for entry in st.session_state.debate_log:
            if entry["type"] == "phase":
                label = PHASE_LABELS.get(entry["phase"], entry["phase"])
                st.markdown(f"---")
                st.markdown(f"### {label}")
            elif entry["type"] == "message":
                with st.chat_message(name=entry["agent"]):
                    st.markdown(entry["content"])

        # Show "thinking" indicator for current agent
        if st.session_state.status == "debating" and st.session_state.current_agent:
            with st.chat_message(name=st.session_state.current_agent):
                st.markdown(f"*{st.session_state.current_agent} is analyzing...*")

        # Show status indicators
        if st.session_state.status == "fetching":
            st.info("Fetching financial data, SEC filings, and market sentiment...")
        elif st.session_state.status == "extracting":
            st.info("Extracting final votes and building scorecard...")

    debate_fragment()
```

IMPORTANT: The fragment MUST render ALL elements (debate log, thinking indicator, status messages) inside its body. Elements drawn to containers OUTSIDE the fragment would accumulate additively on each fragment rerun (documented Streamlit pitfall). By rendering everything inside the fragment, the fragment clears and redraws its body on each rerun.

IMPORTANT: The `run_every` value is computed outside the fragment, at the time `render_debate_section()` is called. When the status changes (e.g., from "debating" to "complete"), the next FULL page rerun will re-call `render_debate_section()` with the new `run_every=None`, stopping the polling. The fragment itself also triggers a full rerun when it detects status changes via `_drain_queue()`.

def render_scorecard():

            '<h2 style="margin:0;color:white;">NO CONSENSUS</h2>'

            '</div>',
            unsafe_allow_html=True,
        )

    # --- Vote table ---
    st.subheader("Individual Votes")

    for vote in sc.votes:
        cols = st.columns([2, 1, 1, 4])

            st.markdown(vote.confidence.value)
        with cols[3]:
            if vote.reasoning:
                st.markdown("; ".join(vote.reasoning[:3]))

IMPORTANT: The `main()` function call is NOT at module level -- Streamlit runs the script top-to-bottom, so place the actual invocation at the bottom:
```python

main()
```
This way, `streamlit run src/tinyic/ui/app.py` executes main() directly. For tests, importing the module runs main() too -- but tests should import specific functions, not run the whole app.

IMPORTANT (thread safety): The background thread NEVER writes to `st.session_state`. All communication goes through `queue.Queue`. The main thread's `_drain_queue()` function (called inside the `st.fragment`) is the only place where queue messages are transferred into session_state. This is the documented thread-safe pattern for Streamlit (see 05-RESEARCH.md Pattern 1).

IMPORTANT (polling): The `st.fragment(run_every=2)` inside `render_debate_section()` handles automatic polling during active states. The fragment reruns independently every 2 seconds, draining the queue and re-rendering the debate log. When the debate completes, `run_every=None` stops polling. This avoids `time.sleep()` which would block the entire script and prevent user interaction.
