Create `src/tinyic/debate/orchestrator.py`:

1. **DebateOrchestrator(TinyWorld)** subclass with:
   - `PHASE_ORDER = [DebatePhase.OPENING, DebatePhase.CROSS_EXAM, DebatePhase.REBUTTAL, DebatePhase.VERDICT]`
   - `__init__(self, name: str, personas: list, data_package: DataPackage, **kwargs)`:
     - Validate `len(personas) >= MIN_PERSONAS` (from constants), raise ValueError if not
     - Validate `len(personas) <= MAX_PERSONAS`, raise ValueError if not
     - Call `super().__init__(name=name, agents=personas, broadcast_if_no_target=True, **kwargs)`
     - Store `self.data_package = data_package`
     - Set `self.current_phase = DebatePhase.SETUP`
     - Set `self._phase_index = 0`
     - Set `self._phase_history: list[str] = []`
     - Call `self.make_everyone_accessible()`
   - `inject_context(self)`:
     - Build preamble using `CONTEXT_PREAMBLE.format(company_name=..., ticker=..., context_data=self.data_package.to_context_string())`
     - Call `self.broadcast(preamble)`
   - Override `_step(self, timedelta_per_step=None, **kwargs)`:
     - If `self._phase_index >= len(self.PHASE_ORDER)`: set `self.current_phase = DebatePhase.COMPLETE`, return `{}`
     - Get current phase from `self.PHASE_ORDER[self._phase_index]`
     - Set `self.current_phase = phase`
     - Get prompt from `PHASE_PROMPTS[phase].format(company=self.data_package.company_name)`
     - Call `self.broadcast_internal_goal(prompt)`
     - Loop through `self.agents` sequentially: call `agent.act(return_actions=True)`, then `self._handle_actions(agent, agent.pop_latest_actions())`
     - Append `phase.value` to `self._phase_history`
     - Increment `self._phase_index`
     - If `self._phase_index >= len(self.PHASE_ORDER)`: set `self.current_phase = DebatePhase.COMPLETE`
     - Return `agents_actions` dict
   - `run_debate(self) -> None`: convenience that calls `self.inject_context()` then `self.run(steps=len(self.PHASE_ORDER), parallelize=False, randomize_agents_order=False)`
   - `@property is_complete(self) -> bool`: returns `self.current_phase == DebatePhase.COMPLETE`

IMPORTANT: The `_step` override must NOT call `super()._step()` -- it replaces the parent's step logic entirely. The parent's `_step` would call `_step_sequentially` or `_step_in_parallel`, but we need our own sequential loop that broadcasts phase goals first.

IMPORTANT: The `run()` method passes `parallelize` and `randomize_agents_order` kwargs through to `_step()`. Our override accepts `**kwargs` to absorb these without error.
