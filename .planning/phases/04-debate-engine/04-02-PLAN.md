Create `src/tinyic/debate/extraction.py` with two functions:

1. **extract_votes(orchestrator: DebateOrchestrator) -> list[Vote]**:
   - Import `ResultsExtractor` from `tinytroupe.extraction`
   - Create a `ResultsExtractor` with:
     - `extraction_objective`: "Extract the investor's FINAL investment verdict from the debate, including their vote, confidence level, and key reasoning."
     - `situation`: f"An investment committee debate about {orchestrator.data_package.company_name} ({orchestrator.data_package.ticker}) has concluded. Extract each investor's final position."
     - `fields`: ["vote", "confidence", "reasoning", "key_risks", "changed_mind"]
     - `fields_hints`: Use the hints from research (04-RESEARCH.md Pattern 4): vote must be BUY/HOLD/SELL, confidence must be HIGH/MEDIUM/LOW, reasoning is 2-4 bullet points, key_risks is top 1-2 risks, changed_mind is boolean.
   - Call `extractor.extract_results_from_agents(agents=orchestrator.agents, verbose=False)`
   - This returns a list of dicts (one per agent). Each dict has the extracted fields as string values.
   - For each result dict + corresponding agent, construct a `Vote` object:
     - `investor = agent.name`
     - `vote = raw_result.get("vote", "HOLD")` -- the fuzzy validator on Vote handles normalization
     - `confidence = raw_result.get("confidence", "MEDIUM")`
     - `reasoning`: parse from the raw string. ResultsExtractor may return a string like "- point 1\n- point 2" or a list. If string, split on newlines and strip "- " prefixes. If already a list, use as-is. If None, use empty list.
     - `key_risks`: same parsing logic as reasoning
     - `changed_mind`: parse boolean-ish value. If string "true"/"yes"/"True" -> True, else False. If already bool, use directly.
   - Return `list[Vote]`
   - Add logging (import logging, get logger for __name__)
   - Wrap extraction call in try/except. If extraction fails for an agent, log warning and create a Vote with vote=HOLD, confidence=LOW, reasoning=["Extraction failed"], changed_mind=False.

2. **build_scorecard(votes: list[Vote], ticker: str, company_name: str) -> Scorecard**:
   - Count votes: bull_count = sum(1 for v in votes if v.vote == VoteChoice.BUY), bear/hold similarly
   - Determine consensus: if one VoteChoice has strict majority (> len(votes)/2), that is consensus. Otherwise None.
   - Return Scorecard with all fields populated.

3. **run_debate(ticker: str, persona_names: list[str], data_package: DataPackage | None = None) -> DebateResult**:
   - Place this function in `__init__.py` (not extraction.py) since it is the top-level public API and imports from multiple submodules.
   - Validate `len(persona_names) >= MIN_PERSONAS` (import from constants)
   - Load personas: `[load_persona(name) for name in persona_names]` (import from personas.registry)
   - Build data package if None: `data_package = build_data_package(ticker)` (import from data.pipeline)
   - Create orchestrator: `DebateOrchestrator(name=f"IC-{ticker}", personas=personas, data_package=data_package)`
   - Run debate: `orchestrator.run_debate()`
   - Extract votes: `votes = extract_votes(orchestrator)`
   - Build scorecard: `scorecard = build_scorecard(votes, ticker, data_package.company_name)`
   - Get transcript: `orchestrator.pretty_current_interactions()`
   - Return `DebateResult(ticker=ticker, company_name=data_package.company_name, scorecard=scorecard, phases_completed=orchestrator._phase_history, transcript=transcript)`

Requires OPENAI_API_KEY. Runs a full debate with 2 personas.
Marked with pytest.mark.live_api so it can be skipped in CI.
"""
import pytest

pytestmark = pytest.mark.live_api


@pytest.mark.timeout(300)
def test_live_debate(has_api_key):
    """Run a complete 2-persona debate with live API calls.

    This is an expensive test (~$1-2 in API costs). Run manually:
        uv run pytest tests/test_debate_live.py -x -v -m live_api --timeout=300
    """
    from tinyic.debate import run_debate

    result = run_debate(
        ticker="AAPL",
        persona_names=["warren_buffett", "benjamin_graham"],
    )

    # Verify structure
    assert result.ticker == "AAPL"
    assert result.company_name  # non-empty
    assert len(result.scorecard.votes) == 2
    assert len(result.phases_completed) == 4
    assert result.transcript  # non-empty

    # Verify each vote is valid
    for vote in result.scorecard.votes:
        assert vote.vote in ["BUY", "HOLD", "SELL"]
        assert vote.confidence in ["HIGH", "MEDIUM", "LOW"]
        assert len(vote.reasoning) > 0
        assert vote.investor  # non-empty name

    # Verify scorecard
    assert result.scorecard.bull_count + result.scorecard.bear_count + result.scorecard.hold_count == 2

    # Print results for manual inspection
    print("\n" + result.scorecard.to_markdown())
