# Requirements Archive: openIC v1.1

**Milestone:** v1.1 — Output Quality, Debate Robustness, and Polish
**Defined:** 2026-03-20
**Completed:** 2026-03-25
**Coverage:** 20/20 validated

## Requirements

### Release Hardening

- [x] **HARD-01**: Migrate edgartools usage from deprecated `edgar.files.html` / `edgar.files.htmltools` to `edgar.documents.HTMLParser` before v6.0 removal — *Validated in Phase 7*
- [x] **HARD-02**: Stabilize live API test path — all 7 currently-deselected `live_api` tests either pass reliably or are removed with documented rationale — *Validated in Phase 7*
- [x] **HARD-03**: Fix Pydantic v1-style `class Config` deprecation in TinyTroupe fork's `SimulationValidator` (use `ConfigDict` instead) — *Validated in Phase 7*
- [x] **HARD-04**: Expose per-debate token/call cost statistics retrieval point from `OpenAIClient.get_cost_stats()` to application layer — *Validated in Phase 7*

### Debate Quality

- [x] **DEBT-04**: Anti-convergence controls that prevent persona opinions from collapsing to consensus over multi-round debates — *Validated in Phase 8*
- [x] **DEBT-05**: Rotating devil's advocate role during cross-examination phase — one persona argues the strongest counter-position, with final votes remaining unconstrained — *Validated in Phase 8*
- [x] **PERS-08**: Lightweight automated differentiation regression tests that detect convergence on fixed company fixtures — *Validated in Phase 8*

### Memo & Disagreement

- [x] **OUTP-03**: Full narrative investment memo with structured sections (thesis, risks, valuation, verdict) synthesized from debate transcript, scorecard, and data package via LLM — *Validated in Phase 9*
- [x] **OUTP-04**: Cross-persona disagreement extraction identifying key dimensions where personas diverge most, with evidence from debate transcript — *Validated in Phase 9*
- [x] **OUTP-05**: Export investment memo and scorecard as Markdown and DOCX via ArtifactExporter with pandoc — *Validated in Phase 9*

### UI Delivery

- [x] **UI-05**: Company data sidebar panel showing key financials, price chart, data freshness indicators, and source warnings — visible during debate — *Validated in Phase 10*
- [x] **UI-07**: Download buttons for memo, scorecard, and transcript in Markdown and DOCX formats — *Validated in Phase 10*
- [x] **OPS-01**: Per-debate token usage and estimated cost displayed in UI after debate completes — *Validated in Phase 10*

### Model Selection

- [x] **CONFIG-01**: User can select the LLM model for a debate from a dropdown in the Streamlit sidebar — *Validated in Phase 11*
- [x] **CONFIG-02**: Selected model overrides `config.ini` at runtime and is passed through to all LLM calls for that debate session — *Validated in Phase 11*
- [x] **CONFIG-03**: Model selection includes a brief description of each model's strengths — *Validated in Phase 11*

### Deep Research Pipeline

- [x] **DATA-06**: Before each debate, the system conducts a structured deep research pass using web search APIs and LLM synthesis — *Validated in Phase 12*
- [x] **DATA-07**: Research brief covers 5 key dimensions: business model, industry trends, management, recent catalysts, analyst perspectives — *Validated in Phase 12*
- [x] **DATA-08**: Research results stored in `ResearchBrief` on `DataPackage` and injected into all persona contexts at debate start — *Validated in Phase 12*
- [x] **DATA-09**: Research step is configurable (can be skipped) and degrades gracefully — *Validated in Phase 12*
